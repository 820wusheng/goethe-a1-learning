🔍 阅读答题Console调试指南

步骤1: 打开试卷页面

打开: uebungssatz01.html

步骤2: 打开Console

按 F12 或 右键 → 检查 → Console标签

步骤3: 在Console中逐行运行以下命令

复制每一行，粘贴到Console，按回车

检查1: 变量是否存在

console.log('answers:', typeof answers);
console.log('userAnswers:', typeof userAnswers);
console.log('submitted:', typeof submitted);

✅ 应该都显示 "object"，如果是"undefined"说明变量未初始化

检查2: 函数是否存在

console.log('selectOption:', typeof selectOption);
console.log('submitAnswer:', typeof submitAnswer);

✅ 应该都显示 "function"，如果是"undefined"说明函数未定义

检查3: 查找第一个阅读选项

const opt = document.querySelector('.option[onclick*="lesen1"]');
console.log('找到选项:', opt);
console.log('选项内容:', opt ? opt.textContent : 'NOT FOUND');

✅ 应该显示选项元素和内容"a Richtig 正确"

检查4: 查找.task父元素

const opt = document.querySelector('.option[onclick*="lesen1"]');
const task = opt.closest('.task');
console.log('找到task:', task);
console.log('task ID:', task ? task.id : 'NOT FOUND');

✅ 应该显示task元素和ID "task-lesen1"

检查5: 手动调用selectOption

const opt = document.querySelector('.option[onclick*="lesen1"]');
selectOption('lesen1', 'richtig', opt);
console.log('调用完成，检查是否添加selected class:', opt.classList.contains('selected'));

✅ 应该显示 true，并且选项应该变蓝保持不消失

检查6: 查看CSS规则

const opt = document.querySelector('.option[onclick*="lesen1"]');
opt.classList.add('selected');
const styles = window.getComputedStyle(opt);
console.log('border-color:', styles.borderColor);
console.log('background:', styles.background);

✅ border-color应该包含 "102, 126, 234"（蓝色），background应该包含浅蓝

步骤4: 报告结果

截图Console输出，告诉我：

  • 哪一步失败了？
  • 错误信息是什么？
  • 检查5执行后，选项是否保持蓝色？

常见问题

  • 变量undefined → JS未加载或作用域错误
  • 函数undefined → script标签位置错误或被覆盖
  • closest返回null → HTML结构错误
  • 手动调用成功但点击失败 → onclick事件被阻止
  • 添加了selected但没变色 → CSS被覆盖
